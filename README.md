# Insurance Policy Analytics

### End-to-End Business & Data Analytics Project

**Project Overview**

This project focuses on analyzing insurance policy data to identify meaningful business insights, understand customer behavior, evaluate policy performance, and support data-driven decision-making.

The project uses five analytical tools to perform end-to-end data analysis.

## Tools & Technologies

- **Microsoft Excel:** Data cleaning, analysis, formulas and dashboard development.
- **SQL (MySQL):** Data querying, aggregations and business analysis.
- **Python:** Data cleaning, exploratory data analysis (EDA), Pandas, NumPy and Matplotlib.
- **Power BI:** Interactive dashboards, KPI tracking and data visualization.
- **Tableau:** Interactive visualizations and analytical reporting.

## Key Areas of Analysis

- Customer demographic analysis
- Insurance policy performance
- Active, lapsed and terminated policy analysis
- Premium and coverage amount analysis
- Claims analysis
- Payment analysis
- Customer segmentation and age group analysis

## Project Workflow

1. Data understanding and collection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. SQL-based business analysis
5. KPI development
6. Dashboard creation
7. Business insights and reporting
